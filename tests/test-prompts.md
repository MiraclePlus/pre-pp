# Pre-PP Skill 测试 Prompts（F25 项目）

> 用于在新电脑上验证 pre-pp skill 完整流程。每个 prompt 模拟创始人首次请求制作 deck 的真实场景。
> 测试前确保已运行 `cd pre-pp && bash setup.sh`

**路演PPT模板**：https://example.com/pitch-template

模板结构参考（40页素材库，按需选用）：
1. 封面（公司名+一句话）
2. 痛点/机会（问题描述+严重程度）
3. 对比（过去做法 vs 我们的产品）
4. 产品（一句话描述+工作原理+优势）
5. 商业模式
6. 进展（增长曲线/客户数/里程碑时间线）
7. 市场（TAM/SAM数字）
8. 团队（创始人+核心角色）
9. 认知/为什么是现在
10. 总结（one-liner + 进展数据 + 市场空间 + 展位号）

## 项目 3：华航轻舟 —— 模组化无人船赋能平台

```
帮我做一个2分钟路演PPT，我是华航轻舟的CEO杨吉凯，我们用模组化方案赋能水域承包商，让高性能无人船开发没有门槛。

请参考我们的路演模板：https://example.com/pitch-template

### 项目核心信息

**一句话定位**：水域版"华为智行"——不卖船，卖造船的能力。

**核心洞察（Insight）**：
- 中国有 1000 亿的水域管养市场
- 全国每年只有 2000 条无人船订单，全部是政府买单
- 真正需要的 1500 家承包商，一条船都没买
- 原因：承包商管十几片水域（巡检/清飘/采样...），需要五六种不同功能的船，每种几十万根本用不起
- 承包商需要的不是一艘船，是"能够根据项目快速造船的能力"——就像维修师傅需要的不是一个扳手，而是一整个工具箱

**产品/方案**：
- 提供智能模组（VIM）+ 系统
- 承包商自己找船厂做船壳，用我们的模组打造自有品牌无人船
- B2B2B模式：不抢承包商生意，赋能承包商做大做强

**关键数据/进展**：
- 0-1验证完成
- 已交付约 800 套产品
- 近 2000 套意向订单
- 成本从 150万 降到 10万（15倍降低）
- 交付周期从 6个月 压缩到 30天（6倍加速）
- 已有年营收几千万的承包商主动来谈合作

**竞争格局**：
- 云洲、欧卡等都在红海抢政府的 2000 条订单
- 1500 家承包商的蓝海市场根本没人做
- 我们发现了别人没看到的市场

**长期想象**：
- 车已经全部智能化，但船还没有——为什么？因为船的场景太复杂、太碎片化
- 我们的模组化方案恰好解决了碎片化问题
- 从"卖模组"到"水域智能化操作系统"——数据生态、行业标准制定者
- 单笔大能活到现在，但总量大才能活在未来
- 目标：让1500家承包商做出自己的智能装备，把市场从2000条做到20000条

### 团队信息

**CEO 杨吉凯**：
- 华中科技大学船舶与海洋工程学院背景
- 全栈软硬件开发能力
- 有国家级项目的海工装备设计开发经验
- 曾接过几千万级别的海工装备大单

**CTO 韵荒博士**：
- 水动力学背景
- 深厚的船舶工程专业能力

**团队核心能力**：全栈自研（从水动力学设计→嵌入式开发→上层软件→系统集成），市面上很难找到替代团队

### PP导师反馈（Max）——必须体现的改进

Max 说了几个关键问题：
1. **前面铺垫太长**：不要花太多篇幅讲"从卖船到卖代码"的转变故事，顶多1-2句话
2. **核心是讲亮点而非道理**：2分钟记不住道理，只能记住亮点
3. **进展是最大亮点**：已签单、有收入、有交付——必须重点讲
4. **需要更大的想象空间**：不能只是"把传统生意做大"，要讲"水域版华为智行"的平台想象
5. **团队不要讲学校**：讲全栈能力和国家级项目经验

Max 建议的三个核心亮点：
- 产品创新：模组化方案 + 成本/周期大幅优化
- 市场验证：已交付800套，意向2000套，蓝海市场无人做
- 长期想象：水域智能化平台/操作系统

### 参考图片

- [无人船作业实拍]：承包商使用我们模组组装的无人船在水域巡检
- [VIM模组展示图]：智能模组拆解/组装示意
- [客户现场]：合作承包商的实际作业场景

10页以内，输出飞书Slides格式。
```
